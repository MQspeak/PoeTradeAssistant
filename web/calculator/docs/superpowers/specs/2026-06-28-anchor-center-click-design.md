# 锚点圆心点击设计

## 背景

当前桌面覆盖层把锚点 `X/Y` 直接当作整个锚点标签的左上角来渲染，同时自动化点击也直接点击 `X/Y`。这导致界面上的蓝色圆点与真实点击位置不一致，真实点击会落在圆点左上方。

## 目标

将锚点统一为“圆心语义”：

- `AnchorPoint.X/Y` 表示蓝色圆点的圆心
- 覆盖层显示时，蓝色圆点圆心与 `X/Y` 对齐
- 拖动锚点时，保存的仍然是圆心坐标
- 自动化点击继续直接点击 `AnchorPoint.X/Y`

## 兼容性

历史配置文件里的锚点坐标来自旧语义，应在加载时自动迁移到圆心语义，避免用户重新标点。迁移规则为：

- `X += 7`
- `Y += 15`

迁移后写入新的坐标语义标记，避免重复迁移。

## 实现范围

- 在核心配置层增加锚点坐标语义标记与几何换算辅助
- 在配置归一化阶段迁移旧锚点坐标
- 在覆盖层渲染时按圆心语义计算标签左上角
- 补充针对迁移和几何换算的测试
