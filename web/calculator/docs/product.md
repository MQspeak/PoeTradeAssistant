# POE2 套利工具产品说明

## 1. 产品概述

POE2 套利工具是一个本地运行的 Path of Exile 2 交易辅助工具，用于帮助玩家维护币种、基础兑换关系，并快速判断不同套利场景是否存在利润空间。

当前仓库里同时存在两套实现：

- 根目录 `index.html` 是可直接双击运行的单文件本地工具，也是 `启动套利工具.cmd` 当前指向的实际入口。
- `src/App.tsx` 是一套基于 React + Vite 的三角套利计算器实现，目前只覆盖三跳闭环套利场景。

从“产品真实使用路径”看，当前主产品应认定为单文件本地工具；React 版本更像并行中的重构或早期替代实现。

## 2. 目标用户

- 需要手工比价、换算币种价值的 POE2 玩家
- 关注符文合成、公式组合、目标物品收益率的交易玩家
- 希望离线、本地、低门槛使用工具的个人用户

## 3. 核心问题

工具试图解决以下问题：

- 币种与物品价值分散，人工换算成本高
- 套利链路涉及多段汇率，容易算错
- 符文套利、公式套利等场景需要复用已有价格数据
- 用户希望在修改价格后立刻看到收益变化，而不是重新整理表格

## 4. 当前产品能力

基于根目录 `index.html`，当前单文件工具已支持 5 个分页：

1. `物品列表`
   - 维护币种/标的名称、分类、金币成本
2. `套利基础交易对列表`
   - 维护币种间的基础汇率关系
3. `套利标的列表`
   - 维护目标物品的多币种价格与收益展示
4. `符文套利`
   - 维护符文相关成本、收益、收益率和金币效率
5. `公式套利`
   - 支持多条成本项、多条收益项、自动结算、保存与编辑

基于 `src/App.tsx`，React 版本当前只支持：

- 三条兑换路径的闭环套利测算
- 每跳手续费与净产出计算
- ROI、闭环倍率、第三跳保本汇率
- 本地存储回填

## 5. 关键用户流程

### 5.1 单文件工具主流程

1. 录入币种与金币成本
2. 维护基础交易对
3. 进入目标分页、符文分页或公式分页
4. 输入价格、数量、成本
5. 实时查看收益率、纯利润、金币效率
6. 保存公式并反复复用

### 5.2 React 三角套利流程

1. 输入初始资金
2. 输入三跳兑换方向、汇率、手续费
3. 系统校验是否闭环
4. 输出净利润、ROI、闭环倍率、保本汇率和每跳明细

## 6. 产品边界

当前版本明确偏向“本地个人工具”，不包含：

- 云端同步
- 多用户协作
- 在线行情抓取
- 账号系统
- 服务端存储
- 自动交易执行

## 7. 当前产品风险

- 仓库存在“双实现并存”问题，用户入口与构建入口不一致
- `npm run build` 产物来自 React 版本，但 `启动套利工具.cmd` 打开的是根目录单文件版本
- 测试脚本全部绑定根目录 `index.html`，无法覆盖 React 版本
- 产品能力在两套实现之间分裂，后续扩展成本会越来越高

## 8. 建议的产品方向

建议先做产品收敛，再继续加功能：

1. 明确唯一主产品实现
2. 明确唯一运行入口与唯一构建产物
3. 明确哪些分页是保留能力，哪些是历史能力
4. 在统一实现上继续扩展公式套利、符文套利和目标套利
